# Sign Language Interpreter - Code Directory

This directory contains all the source code for the sign language interpreter application.

## Main Files

- `final.py` - Main application with all modes
- `alphabet_demo.py` - Dedicated ASL alphabet recognition demo
- `hand_landmarker.task` - MediaPipe hand detection model

## Modes

1. **Alphabet Mode** - Recognizes ASL letters A-Z
2. **Text Mode** - General gesture recognition
3. **Calculator Mode** - Mathematical operations using gestures

## Usage

Run the main application:
```
python final.py
```

Or run the alphabet demo separately:
```
python alphabet_demo.py
```
